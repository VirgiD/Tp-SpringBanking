# Tp-SpringBanking

Aplicación de Home Banking / Cajero Automático desarrollada con Java y Spring Boot como proyecto final de formación.

## Descripción

Proyecto grupal desarrollado durante una formación en Java y Spring Boot.

La aplicación permite gestionar usuarios y cuentas bancarias, realizar transferencias y efectuar operaciones de cajero automático como depósitos y retiros.

El proyecto utiliza una arquitectura organizada en controladores, servicios, repositorios, modelos, DTOs y mappers, incorporando además manejo de excepciones y funcionalidades de auditoría.

## Tecnologías utilizadas

- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- Hibernate / JPA
- MySQL
- Maven
- Lombok
- Git
- GitHub
- Postman

## Funcionalidades

- Registro y gestión de usuarios
- Creación y gestión de cuentas bancarias
- Consulta de cuentas
- Gestión de saldo
- Depósitos
- Retiros
- Transferencias entre cuentas
- Generación de CBU y alias
- Control de fondos insuficientes
- Manejo de excepciones
- Registro y auditoría de operaciones

## Arquitectura

El proyecto se encuentra organizado en diferentes capas:

- **Controllers:** gestión de las solicitudes HTTP y endpoints de la API REST.
- **Services:** implementación de la lógica de negocio.
- **Repositories:** acceso y persistencia de datos mediante Spring Data JPA.
- **Models:** entidades utilizadas por la aplicación.
- **DTOs:** transferencia de datos entre las diferentes capas.
- **Mappers:** conversión entre entidades y DTOs.
- **Exceptions:** manejo de errores y situaciones excepcionales.
